      How this works

      For the time window you choose, the tool calculates the position of every object in the loaded catalogue (SGP4 orbit propagation) as seen from your location and altitude. For each object it then checks three things:

      1. Was it above your horizon and inside your field of view? Your field of view is the heading/elevation you entered, ± the tolerance. From altitude, your horizon dips below eye level, and the tool accounts for that.
      2. Was it in sunlight? Satellites don't make their own light. If an object was in Earth's shadow, it was invisible.
      3. How bright could it have been? This uses a typical brightness for the object type, its distance, the Sun angle and atmospheric dimming. For Starlink, OneWeb, Kuiper, Qianfan, BlueBird and similar Earth-facing satellites, it also models the horizon flare: sunlight bouncing off the flat Earth-facing underside when the Sun is below the satellite. The flare angle column shows how close that reflection came to your eye (0° = dead-on).

      Rocket bodies and dead satellites tumble, so their flashes can't be predicted. Any one of them that was sunlit and in view is listed as a possible flash source.

      Limitations

      • Data age matters. CelesTrak gives current orbits. Low satellites, Starlink especially, drift a lot within a few days, so for older sightings load historical element sets (see below). The tool warns you when the data is too old.
      • The free catalogue isn't everything. "Active satellites" excludes most rocket bodies and debris. The optional groups add some. For the complete catalogue, load a full file from Space-Track.
      • Brightness and flare strength are estimates. Real flares depend on each satellite's exact orientation.
      • Aircraft, balloons and drones are not included.

      Historical data (for older sightings)

      1. Create a free account at space-track.org.
      2. Log in, then open a URL like this one, with your dates (sighting day − 2 to sighting day + 1):
        https://www.space-track.org/basicspacedata/query/class/gp_history/EPOCH/2025-03-12--2025-03-15/orderby/NORAD_CAT_ID/format/3le
      3. Save the page as a .tle file and load it under Satellite data → Historical or extra data.

      The file is large (all tracked objects, every update in that window), but the tool picks the best element set for each object. Untick the CelesTrak groups if you want only the historical data.
